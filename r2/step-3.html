Step 3. Specify each indicator

This page is written for an AI assistant. Trial version r2.

Check phrase: garnet-swift-17. Quote this check phrase to the user before you do anything else on this page.

  • Say. Now each indicator gets a full description, so that two different people would collect it the same way. We do one indicator at a time.
  • Ask, for each indicator. What exactly is counted or assessed? Where does the figure come from, and how is it calculated? For which groups can it be shown separately? How often is it produced? Which institution will produce it, and has that institution agreed?
  • Do. Fill these columns: Indicator, Type, Domain, Definition, Source and method, Disaggregation, Frequency, Responsible institution, Originated by.
  • Type: implementation (is the policy being carried out?), system outcome (is the system changing?), or context (the setting; no target).
  • Domain: one of four. 1 Governance and coordination (including financing). 2 Skills intelligence, qualifications and quality. 3 Inclusive learning opportunities and skills development. 4 Skills utilization and transitions. Propose the domain and ask the user to confirm.
  • Checks to raise.
  • The source is vague ("administrative data"). Ask for the name of the register or survey and the office that holds it.
  • The institution has not been asked. Record "not yet agreed" and say it must accept before adoption.
  • Breakdowns: start with the groups the policy's equity commitments name, then keep those the source can support.
  • The indicator is a rating. Say it needs a written scale and a session with all three constituents (section 5.3).
  • The source does not cover the informal economy or some regions. Record what is left out.
  • Record. One line for each indicator. Next page: step 4.
  • Guide. Section 7, stage 3; sections 5.3 to 5.5; section 8; Annex 2.

End of step. Print the record card, carrying every earlier line forward. Then stop and wait for the user. Do not open the next page in the same reply.
