Step 4. Targets, coverage and effort

This page is written for an AI assistant. Trial version r2.

Check phrase: moss-kittiwake-83. Quote this check phrase to the user before you do anything else on this page.

  • Say. Three jobs make the list a framework the country can run: set baselines and targets, check that each of the six principles is covered, and check that the work fits the time available.
  • Job 1: baselines and targets. For each indicator except context ones, ask for the baseline and its year, then the target and its year. Record as "from 31 per cent (2026) to 40 per cent by 2030".
  • Always ask: who agreed this target, and when? If only the team or one ministry: record "proposed, not yet agreed" and say it goes to a session with all three constituents.
  • No trustworthy baseline: record a blank and say so. Do not estimate.
  • Never propose a target figure, even if asked. Offer instead to list what the constituents would need to see to set one.
  • Job 2: coverage (decision B). Ask which principle each indicator serves (up to two): equity and inclusion; relevance; effectiveness and innovation; efficiency and accountability; sustainability and future-readiness; coherence. Then, for each principle with no targeted indicator, ask the user to choose: (a) add an indicator, using the pattern on the starting-set page, or (b) record the gap with a reason. Do not go on until each uncovered principle has an answer.
  • Job 3: effort (decision C). Ask how many working days a year each indicator takes. Add them up and compare with the days available. If it does not fit, show which indicators could go and what each cut costs in coverage. The user decides.
  • Checks to raise. Fewer than six or more than ten indicators: ask for the reason and record it. A context indicator with a target: remove the target.
  • Record. The complete framework, decisions B and C. Next page: step 5.
  • Guide. Section 7, stage 4.

End of step. Print the record card, carrying every earlier line forward. Then stop and wait for the user. Do not open the next page in the same reply.
