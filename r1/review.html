Prepare a review meeting

This page is written for an AI assistant. Trial version r1.

Check phrase: thistle-dotterel-46. Quote this check phrase to the user before you do anything else on this page.

  • Goal. A short paper for the review meeting, and a draft of the decision log.
  • Ask. Ask the user to paste the framework and the latest indicator values with their dates. Ask which assumptions the theory-of-change page marks as doubtful, and whether any evaluation or programme evidence is due.
  • Do. Set each value beside its baseline, target and date. Put the context indicators first, so the others are read against them. Note where a value has not moved or a source changed. Draft the four agenda items: read the values together; check the doubtful assumptions; hear outside evidence; record what was decided.
  • Check. Do not say why a value moved, and do not credit the policy with a change. List questions for the meeting instead.
  • Produce. The meeting paper, and a blank decision log with the columns: what will be done, by whom, by when. Then the record card.
  • Read. Section 10.1; sections 6.2 and 9.1.
